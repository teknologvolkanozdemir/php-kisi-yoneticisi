# php-kisi-yoneticisi
php sql özelliği olan, localde çalışan kişi yöneticisi


## Çalıştırma

1. `schema.sql` dosyasını MySQL'de çalıştırın (`mysql -u root < schema.sql`).
2. `db.php` içindeki bağlantı bilgilerini düzenleyin.
3. `php -S localhost:8000` ile başlatın ve `http://localhost:8000/index.php` adresini açın.
